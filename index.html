One-click isolation for your Eagle library.

Select a few related items in Eagle and press Focus on Selection. Focus Lens finds the tags they share, then shows you every item in the library that belongs to that “family” — and highlights it in Eagle itself.

  1. Select 1+ items in the Eagle grid
  2. Press Focus on Selection
  3. Toggle tags / Any·All to reshape the lens
  4. Pin it to return later, or push it to Eagle as a tag group / smart folder
